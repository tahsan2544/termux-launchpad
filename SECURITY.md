# Security policy

## Reporting a concern

Please do not publish secrets or exploit details in a public issue. Use GitHub's private vulnerability reporting feature if it is enabled for this repository, or contact the maintainer privately through the contact listed on the repository profile.

## Sensitive data

Never submit an OmniRoute API key, OpenCode config containing a key, GitHub token, SSH private key, `.env`, or private project source as an issue attachment.

## Scope and limitations

Termux Launchpad is a local convenience toolkit. It is not a security boundary, sandbox, antivirus, or guarantee of compatibility. OpenCode and OmniRoute are third-party projects and must be updated using their upstream guidance. Read source scripts before running them and use official sources where possible.
