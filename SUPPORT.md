# Support

Before opening an issue:

1. Run `lpdoctor` and `dashboard`.
2. Read `docs/TROUBLESHOOTING.md`.
3. Search existing issues for the exact error.
4. Include Android version, Termux source, CPU architecture if known, the exact command, and the full relevant error output.

Never post passwords, API keys, auth tokens, private project files, or the OpenCode config created by `omniconnect`.
